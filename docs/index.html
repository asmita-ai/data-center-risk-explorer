Layer 3: real-data benchmark

A Python benchmark on the open Battery Failure Databank (~365 calorimeter abuse tests on commercial Li-ion cells across ~31 cell designs). It evaluates how well total heat release can be estimated from cell metadata and ejected mass, compared with a naive baseline, and whether the model generalizes to unseen cell designs.

Results (10 repeats of 5-fold group CV by cell design): Using strictly pre-test metadata (Tier A), a Random Forest estimated total heat yield with R² = 0.671 ± 0.254 and MAE = 8.798 ± 1.959 kJ (± values represent standard deviation across splits, not a confidence interval). Including in-test trigger parameters (Tier B) showed virtually no improvement over Tier A. However, including post-test ejecta mass and observed failure mechanisms (Tier C) significantly increased performance to R² = 0.801 ± 0.133 and MAE = 7.211 ± 1.573 kJ, with Ridge and Random Forest performing about equally well. The clear finding is that post-test measurements add a lot of explanatory power.

Leakage note: Columns containing explicit downstream heat measurements were excluded. Including batch IDs (Test-Series) did not artificially inflate unseen-design performance because the IDs themselves were entirely unseen in the test folds. No novelty is claimed; this is a benchmark/replication exercise, and conclusions apply only to this specific dataset.
